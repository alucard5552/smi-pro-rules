# SMI Helper AI Bridge & Control Center — UI Design & Rules

Cyberpunk Glassmorphism Web App UI & PRO Rules Engine for Arizona RP Drake [31].

## 🎨 Visual Design & UI Overview
- **Theme**: Cyberpunk Neon Glassmorphism (`#07090e`, glowing borders, semi-transparent frosted cards).
- **Accents**: Neon Cyan (`#00f3ff`), Purple (`#b026ff`), Emerald Green (`#00ff88`), Gold (`#ffaa00`), Crimson (`#ff0055`).
- **Typography**: Responsive UI stack with monospaced code blocks (`Consolas`, `Courier New`).
- **Interactive Components**:
  - Live AI Bridge status & telemetry cards
  - Account manager with instant status indicators
  - Live PRO rules editor with syntax highlighting
  - Fast search & test playground for ad re-training
  - One-click dark/neon theme switching & spring animations

## 📁 Repository Structure
- `index.html` / `ui/index.html` — Full standalone Cyberpunk Glassmorphism UI (HTML5, CSS3, SVG, animations).
- `CUSTOM_LEARNED_RULES.txt` — Custom learned rules, radio broadcast templates, and exception registry.
- `GEMINI_NEW_CHAT_MASTER_PROMPT.txt` — Master PRO regulatory prompt for Arizona RP.
- `templates/ADS.json` — Canonical PRO ad templates & examples.
